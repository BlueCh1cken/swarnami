# What to contribute:
- New vocabulary
- Grammar Suggestions
- Script improvements
- Documentation
- Example Texts
- Learning Resources
- Software tools about Swarnami

# Contribution Criteria:
- Easy to write in Bharati Script
- Easy to pronounce
- Different from most other words
- Simple Words
  Language, Political and Religious

# How to Contribute:
## Github Discussions
To brainstorm ideas, you can discuss in Github Discussions. Please be kind when discussing possible contibutions, and be respectful of different (especially language) backgrounds, as the biggest goal of Swarnami is to be a collaborative language which is a mix of all the Indic language families.
