# Contributing

## What to contribute:
- New vocabulary
- Grammar Suggestions
- Script improvements
- Documentation
- Example Texts
- Learning Resources
- Software tools about Swarnami

## Contribution Criteria:
- Easy to write in Bharati Script
- Easy to pronounce
- Different from most other words
- Simple Words
  Language, Political and Religious

## How to Contribute:
### Github Discussions
To brainstorm ideas, you can discuss in Github Discussions. Please be kind when discussing possible contibutions, and be respectful of different (especially language) backgrounds, as the biggest goal of Swarnami is to be a collaborative language which is a mix of all the Indic language families.

### Pull requests
For concrete changes, you can submit a pull request. This is after the discussion processes are finished.
Please include:
- Type of addition to Swarnami (Word Order, Nouns, Verbs, etc.)
- Origin language family (if any)
- Statment if change is major or minor (see procedures in constitution for each)
- Details of the addition
- A one line rationale for why this is suitable to the principles
- A checklist of all the non-negotiable prerequisites, all adhered to, shown below:

---
1. Popularity /10
2. Ease of understanding /10
3. Familiarity /10
---
